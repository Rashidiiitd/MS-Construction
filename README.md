# MS Construction Website

A simple, mobile-first bilingual (English/Hindi) website for MS Construction.

## Project structure

```
.
├── index.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   ├── js/
│   │   └── main.js
│   └── images/
│       ├── steel-structure-erection.jpg
│       ├── roof-sheeting-wall-cladding.jpg
│       ├── mezzanine-floors-accessories.jpg
│       └── finishing-handover.jpg
└── README.md
```

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

## Website features

- English/Hindi language switch
- Responsive mobile navigation and layout
- Services and work gallery
- Tap-to-call and WhatsApp enquiry links
- Enquiry form that prepares a WhatsApp message (the visitor presses Send in WhatsApp)
